03 / What Changed

入れ替えを重ねても、残したもの。

補完枠の役割は何度も変えた。しかし、構築を動かす3体は同じ。変遷から残った考え方を整理した。

01 / CORE

3体のサイクルは固定

スカーフサザンドラの高速とんぼ、メガグソクムシャの先制技＋とんぼ、ロトムのボルチェンという核は、補完枠の試行中ずっと使い続けた。前期から最終版にかけては、耐久配分やドラゴン技・素早さ下降補正を再調整している。

02 / SECOND MEGA

裏メガは役割から逆算

キラフロル→リザY→特殊バシャ→メガガブZを試し、最後は炎・鋼への圧力といわなだれによる飛行への打点を持つ物理メガバシャーモに戻した。

03 / TWO SUPPORTS

対応の薄さは残り2枠で埋める

ガラキンでアシレーヌ・オオニューラ・ドヒドイデへ対応しつつ再生力で回す。ガブリアスは電気無効・タスキ・ステロで試合の入口を担当。

※この3組は「採用枠と役割がどう変わったか」を見せる編集上の比較です。各ポケモンが同時に1対1で交代した、という実際の操作順を示すものではありません。

05 / Selection Logic

基本選出を持つ。
でも、固定しない。

選出の基本形は「サザンドラ＋メガ枠＋1体」。まず相手に通るメガ枠を選び、最後にミトム・ガラキン・ガブから必要な受け先を決める。ただしフェアリーが多くサザンが機能しない相手には、サザン抜きの3体選出も用意する。

アシレーヌ＋ミミッキュ＋メガピクシー（またはメガフラエッテ）など、フェアリーが重なっている並び。スカーフの悪・竜技を一貫させにくいので、メガグソク＋ガラキン＋ミトムなどで耐性から選出する。

06 / Remaining Questions

6体の形は決まった。あとは実戦で磨く。

技の採用理由は定まったため、使ってみて不足する部分を見つける段階。勝率や順位は記録できた段階で追記する。

01 / DAMAGE

りゅうのはどうの確定数

C特化のりゅうのはどうでH2メガガブリアスZやメガボーマンダを高乱数で倒す想定。耐久振りやチョッキ、受け出し先も含めて、倒し損ねるパターンを把握したい。

02 / RECOVERY

HDオボンの物理受け性能

基本選出での特殊受けは厚くなった一方、物理には鬼火に依存する。初手ガブ・バシャ・竜舞勢への切り返しを、対戦しながら確認する。

03 / HAZARDS

ステルスロックと交代回数

グソクを何度も着地させる一方でステロ除去はない。メガ前に岩で25%削られ、タスキガブも設置で行動保証を失う。初手の展開をどこまで止められるかが課題。

04 / SELECTION

サザンを出さない試合の完成度

フェアリーが多い並びではグソク＋ガラキン＋ミトムなどに切り替える。スカーフの速度を失った選出でも、十分に回して勝てるかを検証する。

この構築で目指すのは、サイクルを回せること自体ではない。相手の6体を見て、勝ち筋を持った3体を選び切ること。
